# 💰 Expense Tracker App

A simple and interactive Expense Tracker web application built using Python and Streamlit.  
It helps users track daily expenses, analyze spending patterns, and improve financial habits.

---

## 🚀 Live Features

- ➕ Add daily expenses (date, category, amount, note)
- 📊 View expense history in a table
- 💰 Track total spending
- 📈 Category-wise spending analysis (bar chart)
- 🧠 Simple and clean UI

---

## 🛠️ Tech Stack

- Python 🐍  
- Streamlit ⚡  
- Pandas 📊  
- Matplotlib 📉

2. Install dependencies

3. Run the app
python -m streamlit run app.py
